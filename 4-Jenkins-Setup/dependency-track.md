# Dependency-Track Setup

Goal: install Dependency-Track so Jenkins can upload image SBOMs generated by
Trivy.

Dependency-Track URL after install:

```text
http://dependency-track.192.168.0.110.nip.io
```

## 1. Files

```text
4-Jenkins-Setup/
  dependency-track.md
  dependency-track-secrets.yaml
  dependency-track-postgresql-values.yaml
  dependency-track-values.yaml
  dependency-track-httproute.yaml
```

The old notes used `hostPath`, `local-path`, and node affinity. This cluster now
uses Longhorn, so PostgreSQL and Dependency-Track API storage use Longhorn PVCs.

## 2. Secrets

Add these values to local `.env`:

```bash
DEPENDENCY_TRACK_POSTGRES_ADMIN_PASSWORD=change-me
DEPENDENCY_TRACK_DB_PASSWORD=change-me
```

Apply:

```bash
set -a
source .env
set +a

envsubst < 4-Jenkins-Setup/dependency-track-secrets.yaml | kubectl apply -f -
```

## 3. Install Helm Repositories

```bash
helm repo add dependency-track https://dependencytrack.github.io/helm-charts
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update
```

This setup uses the stable HTTP Helm chart:

```text
dependency-track/dependency-track 1.3.0
Dependency-Track app version 4.14.3
```

The newer v2 chart / Dependency-Track 5 line is still release-candidate/OCI
oriented in the upstream chart flow, so this doc stays on the stable chart for
now.

## 4. Install PostgreSQL

Dependency-Track should not run on the embedded H2 database for a persistent
cluster install. Install PostgreSQL first:

```bash
helm upgrade --install dtrack-postgresql bitnami/postgresql \
  --namespace dependency-track \
  --version 18.7.13 \
  --values 4-Jenkins-Setup/dependency-track-postgresql-values.yaml \
  --timeout 10m \
  --wait
```

Check:

```bash
kubectl get pods -n dependency-track
kubectl get pvc -n dependency-track
```

## 5. Install Dependency-Track

```bash
helm upgrade --install dtrack dependency-track/dependency-track \
  --namespace dependency-track \
  --version 1.3.0 \
  --values 4-Jenkins-Setup/dependency-track-values.yaml \
  --timeout 20m \
  --wait
```

The chart deploys an API server and frontend. Chart `1.3.0` does not have a
first-class `database:` values block, so the API server uses
`ALPINE_DATABASE_*` environment variables to connect to PostgreSQL.

Check:

```bash
kubectl get pods -n dependency-track
kubectl get svc -n dependency-track
kubectl get pvc -n dependency-track
```

## 6. Expose Dependency-Track

```bash
kubectl apply -f 4-Jenkins-Setup/dependency-track-httproute.yaml
kubectl get httproute -n dependency-track
```

Open:

```text
http://dependency-track.192.168.0.110.nip.io
```

Initial login:

```text
admin / admin
```

Change the admin password after first login.

## 7. Create Jenkins API Key

In Dependency-Track:

```text
Administration > Access Management > Teams
```

Create or choose a team that can upload BOMs, create an API key, and add it to
local `.env`:

```bash
DEPENDENCY_TRACK_API_KEY=odt_...
```

Then update Jenkins secrets before the Jenkins Helm upgrade:

```bash
set -a
source .env
set +a

export GITHUB_DOCKER_AUTH=$(printf "%s:%s" "$GITHUB_USERNAME" "$GITHUB_TOKEN" | base64 -w0)
envsubst < 4-Jenkins-Setup/jenkins-secrets.yaml | kubectl apply -f -

helm upgrade --install jenkins jenkins/jenkins \
  --namespace jenkins \
  --values 4-Jenkins-Setup/jenkins-values.yaml \
  --timeout 10m \
  --wait
```

Jenkins exposes the API key as the Secret Text credential
`dependency-track-api-key`.

## 8. Enable Upload In Jenkinsfile

After Dependency-Track is reachable and the Jenkins credential exists, set:

```groovy
dependencyTrackEnabled: true
```

The release pipeline flow becomes:

```text
Build Images
  -> image-artifacts/*.docker.tar
  -> image-artifacts/images.txt

Image Security Scan
  -> trivy image --input image-artifacts/*.docker.tar
  -> trivy-image-reports/*.trivy.json

Generate Image SBOM
  -> sbom-reports/*.cyclonedx.json
  -> optional upload to Dependency-Track
```
